# Tryclean-craft brief

Steal structure and feel from tryclean.ai. Do not clone Clean.

## Steal

- Near-black canvas, warm-white type, muted grey body
- Electric-blue accents for focus / active only
- Floating pill nav
- White primary pill CTA: Join waitlist →
- Dense dark UI on atmospheric plates (abstract depth — not beach/forest ads)
- Huge rounded bands, 2-col text + UI
- Staged scroll / subtle motion; reduced-motion safe
- Short copy

## Forbid

- Clean brand, copy, ICP, leads, CRM
- Fake logos or metrics
- Mem0 lavender / cartoon clouds
- Mixed demo stages
- MCP or SLM claimed live
- Fake waitlist success without Redis

## Section map

1. Floating pill nav — How · Product · Waitlist · Join waitlist → · Contact
2. Dark hero — chip · H1 with *understands* · 1-line · dual CTAs · demo plate peeking
3. Demo plate — atmospheric photo + dense UI; Notes → Compact → Reason → Answer exclusive; ≥50% in view · ~36s · Replay
4. Why 2-col plate — paste vs living memory / refuse bridges
5. How 2-col — short steps + staged UI on plate
6. SLM pre-launch / not live
7. Surfaces — Claude / ChatGPT / Cursor · MCP coming soon
8. Waitlist honest
9. Minimal dark footer

## Locks

- H1: AI memory that *understands* you. Instrument Serif italic only on understands
- Spine: Compact → Reason → Deliver
- Living memory: preferences / decisions / open loops
- No Distill / Vault
- Waitlist never fake-success; 503 honest
