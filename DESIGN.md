# Archilas Site — Design System

Mem0 rhythm: blue-wash hero with a peeking demo, black architecture band, cream how-it-works.

## Type

- Topbar: all-caps Geist, weight 450, tracking `0.16em`.
- H1: Geist 650 + Instrument Serif italic on **understands** only.
- Dual CTAs: pill Join waitlist → + outline Contact.

## Rhythm

- Hero: soft blue wash (no cartoon clouds), badge → H1 → two-line sub → pill CTAs → selector pills → demo peek.
- Demo: café Fridays story. Phone messages appear → lines → ✓ Saved → bundle rows → smart answer. ~14s, once in view, Replay.
- Why better: black band, three architecture points. No Distill / Vault / SOC2.
- How it works: cream stepper + pills.
- Waitlist: cream, dual buttons.
