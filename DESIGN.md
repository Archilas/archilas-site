# Archilas Site — Design System

Airy paper. One dark hero stage. Hex lives in `src/styles/tokens.css` (JS mirror: `src/styles/tokens.ts`).

## Color

| Token | Value | Role |
|------|-------|------|
| `--bg` | `#F7F7F5` | Page ground |
| `--surface` | `#FFFFFF` | Forms, rail tiles |
| `--ink` | `#0A0A0A` | Display, headings, waitlist CTAs |
| `--body` | `#3F3F46` | Body |
| `--muted` | `#737373` | Labels, captions |
| `--line` | `#E5E5E5` | Hairlines |
| `--inverse` | `#0A0A0A` | Hero stage, supporting cards |
| `--signal` | `#0F766E` | Active tab underline, Run fill |
| `--focus` | `#0F766E` | Focus rings |

No rust, mint, aqua fills, orbs, gradients, or traffic-light dots. Shadows only on the hero box and the two supporting cards.

## Signatures

- H1: Archilas keeps a *record* your AI can use. Only `record` is Instrument Serif italic.
- Hero keeps email + solid ink Join waitlist. Play the demo runs the stage.
- Agency tabs swap Transcript → Compact → Reason → Deliver → Record.
- Archilas window chrome: mono object name. No macOS dots.

## Layout

- Nav: How it works / Product / Waitlist.
- Landing: Hero (form + stage) / two supporting cards / Surfaces rail / Waitlist / Footer.
