# Archilas Site — Design System

Airy paper, cloud-sky hero only. Hex lives in `src/styles/tokens.css`.

## Color

| Token | Value | Role |
|------|-------|------|
| `--bg` | `#F7F7F5` | Page ground below the hero |
| `--surface` | `#FFFFFF` | Demo box, modal, rail tiles |
| `--ink` | `#0A0A0A` | Display, headings, Join waitlist |
| `--body` | `#3F3F46` | Body |
| `--muted` | `#737373` | Labels, captions |
| `--line` | `#E5E5E5` | Hairlines |
| `--signal` | `#0F766E` | Active demo tab underline, Play fill |
| `--focus` | `#0F766E` | Focus rings |

Hero sky is CSS only: `#DCEBF7` → `#F7F9FA` plus soft white radials. No photography, SVG clouds, rust, mint fills, or traffic-light dots.

## Signatures

- H1: AI memory that understands you.
- Hero and waitlist band: solid ink `Join waitlist →` (modal) beside `Contact`.
- Demo is a white elevated box. Tabs: Detailed notes / Compacted memory / Smart answer.

## Layout

- Nav: How it works / Product / Waitlist, plus Join waitlist → and Contact.
- Landing: cloud-sky hero + demo / two teaching cards / Surfaces / waitlist band / Footer.
