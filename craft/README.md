# Mem0 rhythm

- Topbar is all-caps with open tracking. z-50 + blur so it stays above the demo.
- Hero is `#E8F0F9→#F7F7F5` plus large soft white radials. Instrument Serif italic only on “understands.”
- Demo autoplays once in view (~22s), one stage at a time: notes → compact → retrieve → answer. Replay. No “0 lines” first paint.
- Why-better is the SLM differentiator band (in development / early access — not live). Then a light stepper with Compact / Reason / Deliver sublabels.
- Waitlist persists to Upstash Redis when store env is set; otherwise the API fails closed.
